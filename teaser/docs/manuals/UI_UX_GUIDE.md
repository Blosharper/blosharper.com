## 🎨 화면 레이아웃

### 전체 구조

Blosharper는 **단일 화면 기반**의 게임으로, 모든 요소가 하나의 뷰에 구성됩니다:

```
┌────────────────────────────────────────────────────────────┐
│ [상단 대시보드 (가로 그리드)]                                │
│ 라운드(메뉴) │ 딴돈/판돈 │ 치기/묻기 │ 배점 × 배수 │ 스탯 │ 스킬 보따리 │
├────────────────────────────────────────────────────────────┤
│                                                            │
│   [스마트 알림 / 점수 연출]                                 │
│                                                            │
│              [카드 영역]  손패 1~8장          [덱]          │
│                                                            │
├──────────────────┬─────────────────────────────────────────┤
│ [플레이어 덱]     │ [보톰바]  족보 알림                      │
│ 초상 · 레벨       │ [묻기] [치기] (+스톱·탄·낱장치기·무르기) │
│ 체력 · 지갑       │                                         │
│ [스탯] [뒷골목]   │                                         │
└──────────────────┴─────────────────────────────────────────┘
```

- **상단 대시보드**: 화면 상단을 가로지르는 그리드. 라운드 배지(누르면 게임 메뉴), 딴돈/판돈, 남은 치기·묻기 횟수, 배점 × 배수, 스탯 4종(구라·눈치·배짱·요행), 스킬 보따리로 구성됩니다.
- **플레이어 덱 (좌하단)**: 캐릭터 초상과 레벨, 체력 게이지, 지갑, 그리고 [스탯]/[뒷골목] 버튼이 모여 있습니다.
- 별도의 ⚙️ 설정 버튼은 없습니다 — 게임 메뉴는 라운드 배지 클릭 또는 ESC로 엽니다.

### 주요 UI 진입점

게임 플레이 중 다양한 UI가 오버레이로 나타납니다:

|      진입점       | 화면/모달                                                 | 설명                                 |
| :---------------: | :-------------------------------------------------------- | :----------------------------------- |
| 🚪 **뒷골목 버튼** | [마스터 숍](#마스터-숍)                                   | 뒷골목 상점 (회복, 기술, 은행 등)    |
| **라운드 클리어** | [정산 화면](#정산-화면) → [기술 선택](#보상-모달-시스템)  | 점수 상세 내역 → 3가지 기술 중 선택  |
|  **보스 클리어**  | 정산 → [보상의 문](#보스-클리어-리워드) → 고른 문의 보상 화면 | 문 선택 → 위탁·손기술·봉투 중 고른 것만 |
|    **레벨업**     | 레벨업 모달                                               | 스탯 포인트 획득 알림                |
| **ESC / 라운드**  | [게임 메뉴](#게임-메뉴-시스템)                            | 재시작, 설정, 종료 등 메뉴 진입      |
|     **I 키**      | 인벤토리 패널                                             | 보유 기술 목록 및 각성               |
|     **H 키**      | 족보 이력 모달                                            | 사용/버린 카드 기록 (카드 선택 모달) |
|     **D 키**      | 덱 뷰어                                                   | 남은 카드 확인 (월별)                |
|     **M 키**      | 마스터숍                                                  | 뒷골목 이동 (아이템/기술/은행)       |
|     **T 키**      | 스탯 관리                                                 | 캐릭터 스탯 투자/관리 화면           |

## 🎮 메인 게임 화면

### 상단 대시보드

화면 상단을 가로지르는 레트로 계기판 스타일 그리드:

- **라운드**: 현재 라운드 번호 — 배지를 누르면 게임 메뉴가 열립니다
- **딴돈/판돈**: 이번 라운드에 딴 돈과 목표 금액
- **치기/묻기**: 남은 손패 플레이·묻기 횟수
- **배점 × 배수**: 현재 선택한 패의 실시간 점수 미리보기
- **📊 스탯**: 구라/눈치/배짱/요행 4종 (마우스 오버 시 상세 정보, 클릭 시 스탯 관리)
- **스킬 보따리**: 보유 카드 스킬 (클릭 시 인벤토리)

### 플레이어 덱 (좌하단)

화면 좌측 하단에 위치:

- **초상 · 레벨**: 캐릭터 초상화와 현재 단(Level), 화면 하단의 경험치 바
- **❤️ 체력**: 현재 체력 게이지 (빈사 시 RED 경고)
- **💰 지갑**: 보유 금액
- **[스탯] / [뒷골목]**: 스탯 관리 화면과 뒷골목 상점 진입 버튼

### 카드 영역

화면 중앙 하단:

- **손패 8장**: 항상 월 순으로 정렬 (1월~12월, 귀는 13월)
- **자동 스케일**: 화면 크기에 따라 0.8~1.0배 자동 조정
- **카드 월 표시 (단축키)**:
  - **Alt 키 (홀드)**: 누르고 있는 동안 모든 카드 좌상단에 상세한 월 정보(예: "1월 송학", "12월 비" 등)가 노출됩니다.
  - **F9 키 / 패드 R3 (토글)**: 누를 때마다 화면 상의 모든 카드 좌상단에 상세한 월 정보가 나타나거나 사라집니다.

### 액션 버튼

- **치기**: 선택한 카드로 족보 제출
- **묻기**: 선택한 카드를 버리고 새 카드 받기
- **무르기 (⏳)**: 직전 치기를 취소하고 카드/턴/점수/칩을 직전 상태로 복구 (되돌리기 효과를 주는 기술·족보 발동 시에만 표시, `U` / `Ctrl+Z`)
  - **완전 롤백** — 스냅샷 시점의 모든 상태(Chips, Score, Card, Turn)를 패널티 없이 100% 복원합니다.
- **스톱**: 목표 달성 시 나타남, 판 즉시 종료 (`F7`)
- **고**: 목표 달성 후 계속 진행 (목표 2배 증가)
- **탄 (🎴) / 낱장치기 (🤏)**: 해당 손기술을 보유했을 때만 나타나는 조건부 버튼 — 사용 조건을 채우지 못하면 비활성화됩니다.

## 🔔 스마트 알림 시스템

점수 미리보기 영역 상단에 위치한 **SmartNotification**은 현재 게임 상태를 실시간으로 안내합니다.

### 동적 상태 알림

- **패 선택 전**: "패를 선택하세요 | 남은 점수 표시"
- **패 선택 중**: "족보명 | +XXX점 예상"
- **위험 감지**: "⚠️ 점수미달! (예상: XXX점)"
- **목표 달성**: "목표 갱신 | 다음 고 판돈"

### 딜러의 손짓

약 10% 확률로 딜러가 손패와 덱을 훑어 "1장 모자란 족보"를 넌지시 귀띔합니다:

- "삼광까지 광 1장이야"
- "홍단까지 1장이야"
- "고도리까지 새 한 마리야"

짚이는 것이 없을 때는 감으로만 흘립니다:

- "내 감이 맞다면... 이번 판 크게 올 거야"
- "조심해, 뭔가 낌새가 이상해"

### CRT 스타일 전환

메시지 변경 시 레트로 아케이드 효과:

- 3D 회전 압축 (rotateX)
- 서브 메시지 깜빡임
- 흑백 고대비 테마

## 📊 실시간 점수 미리보기

화면 중앙 하단의 **점수 × 배수 박스**:

### 표시 내용

- **족보명**: 현재 선택한 패의 족보
- **배점**: 패 점수 + 조합 보너스 + 기술 보너스
- **배수**: 조합 배수 + 기술 배수
- **조합패**: 2개 이상 족보 성립 시 "💎 MULTIPLE! 💎"

### 클리어 가능 표시

목표 달성 가능 조합이면 **빛나는 효과** + 황금 테두리

### 툴팁

- **배점**: 마우스 오버 시 점수 계산 상세 (패/조합/기술 분해)
- **배수**: 기본 배수 + 기술 배수 상세

## 💰 정산 화면

라운드 클리어 시 **SettlementBreakdown**이 나타나 점수를 화려하게 정산합니다!

### 표시 항목 (순서대로)

점수 항목이 **아래→위**로 순차 등장:

1. 기본 점수
2. 족보 점수
3. 구라 보너스
4. 배짱 보너스
5. 눈치 보너스 (보스전)
6. 기술 보너스
7. 눈속임 차감 — 덱 버프로 부풀려진 점수를 정산에서 걷어냄 ("눈속임 (돈 아님)")
8. 뽀찌 (입막음) 페널티
9. GO 보너스 (1GO, 2GO...)
10. 보스 클리어
11. 피바라기 (×10배)
12. 🌠 광의 축복 (+N%)
13. 🔥 받아치기 보너스 — 보스 도전 성공 시 (×N배)
14. 타짜 (×2배)

### 인터랙션

- **클릭**: 현재 항목 즉시 표시
- **3번 연타**: 전체 스킵 → 최종 결과
- **자동 진행**: 모든 항목 표시 후 다음 화면

### 시각 효과

- **심장 박동**: 새 항목마다 펄스
- **화면 흔들림**: 큰 점수 획득 시
- **플래시**: 잭팟 보너스
- **스케일 업**: GO 횟수↑ → 패널 크기↑ (최대 1.5배)
- **숫자 롤링**: 부드러운 카운팅 애니메이션

## 🏪 마스터 숍

플레이어 덱(좌하단)의 **[뒷골목]** 버튼 또는 **M 키**로 진입.

### 화면 구성

```
┌───────────────────────────────────────────┐
│ [Background: Back Alley Atmosphere]       │
│  ┌──────────┬──────────────────────────┐  │
│  │Character │ [Dialogue Box]           │  │
│  │ (점주)    │  Speaker + Text (Typing) │  │
│  │ (스승)    │                          │  │
│  │ (상무)    │  [Menu Grid]             │  │
│  │          │ ┌──┬──┬──┬──┐            │  │
│  │          │ │💊│🩹│🍵│🛡️│            │  │
│  │          │ ├──┼──┼──┼──┤            │  │
│  │          │ │🧠│📜│👂│🏧│            │  │
│  │          │ ├──┼──┼──┼──┤            │  │
│  │          │ │📥│📖│🎴│🚪│            │  │
│  │          │ └──┴──┴──┴──┘            │  │
│  │          │ [Player Status]          │  │
│  │          │ 💰 Money/❤️ HP/💸 Debt   │  │
│  └──────────┴──────────────────────────┘  │
└───────────────────────────────────────────┘
```

### 화자 전환 (마우스 오버)

메뉴 항목에 마우스를 올리면 그 장사의 주인이 응대합니다. **점주는 게임 진행(페이즈)에 따라 바뀝니다**:

- **점주**: 회복 아이템, 보험, 뇌세척, 떠나기 — 첫 페이즈의 점주는 💃 홍마담
- **🕵️ 스승 (노인)**: 기술 전수, 정보 구매 (해금 필요)
- **🕴️ 상무**: 빚 상환과 은행 업무 (출금/입금/통장)

### 메뉴 아이템

최대 13종의 항목이 있으며, 게임 진행(페이즈)에 따라 열리고 닫힙니다:

|       아이템       | 효과                             | 조건                                                    |
| :----------------: | :------------------------------- | :------------------------------------------------------ |
|    💊 **알약**     | HP +10                           | -                                                       |
|   🩹 **반창고**    | HP +30                           | -                                                       |
|    🍵 **약차**     | HP 100% 회복                     | -                                                       |
|  🛡️ **생명 보험**  | 1회 부활 (레벨/스탯 보존)        | 뒷골목 소문 정보 구매 + 빚 0 상태로 5라운드 이상 도달   |
|   🧠 **뇌세척**    | 전체 스탯 초기화 + 포인트 환급   | -                                                       |
|  📜 **기술 전수**  | 무작위 고급 카드 스킬            | 스승 등장                                               |
|  👂 **정보 구매**  | 게임 정보 1개                    | 스승 등장                                               |
|   💸 **빚 상환**   | 빚 갚기                          | 페이즈 1 전용. 빚을 다 갚으면 🚪 **상무 만나기**로 바뀜 |
|  🏧 **은행 출금**  | 은행 잔고에서 인출               | 페이즈 2부터                                            |
|  📥 **은행 입금**  | 지갑의 돈을 은행에 예치          | 페이즈 2부터                                            |
|  📖 **통장 내역**  | 은행 거래 내역 확인              | 페이즈 2부터                                            |
| 🎴 **화투통 개조** | 사용하는 화투통(덱 구성) 변경    | 특정 조건 해금                                          |
|   🚪 **떠나기**    | 상점 나가기                      | -                                                       |

### 물가 변동

가격은 **동적 계산**:

- **레벨 비례**: 1.15^(Lv-1) 배율
- **빚쟁이 할증**: 빚 있으면 +20%
- **눈치 할인**: 최대 -60%

### 🏦 은행과 통장

페이즈 2부터 뒷골목에서 은행 업무를 볼 수 있습니다:

- **출금/입금**: 금액 지정 모달에서 처리하며, 메뉴 설명에 수수료(%)가 함께 표시됩니다.
- **통장 내역**: 최근 거래를 시간순으로 보여줍니다. 각 줄에 라운드, 거래 유형(입금/출금/보관료/연체 이자 등), 원금, 은행 몫, 처리 후 잔고가 표기되어 잔고의 흐름을 그대로 추적할 수 있습니다.

### 🎴 화투통 개조

해금 후에는 뒷골목에서 사용할 화투통(덱 구성)을 바꿀 수 있습니다. 선택 모달에서 각 화투통의 구성과 특성을 비교해 고르며, ESC로 취소할 수 있습니다.

**개조 삯 패널**: 화투통 카드 아래에 **개조 삯**과 **가진 돈**이 나란히 서고, 그 아래 한 줄로 지금 무슨 일이 일어나는지 설명이 붙습니다. 어떤 통을 짚었느냐에 따라 네 가지로 갈립니다.

|      고른 통       | 삯 표시           | 안내 문구가 말하는 것                            |
| :----------------: | :---------------- | :----------------------------------------------- |
|  지금 예약된 통    | 없음 (예약 그대로) | 다른 화투통을 골라야 삯이 붙습니다               |
|  지금 쓰는 통으로  | **환불 금액**     | 예약을 물리고 예약금을 돌려받습니다              |
| 예약을 다른 통으로 | 없음 (예약금 그대로) | 예약금은 그대로 두고 통만 바꿉니다              |
|   새로 예약        | **삯 금액**       | 삯은 지금 치르고, 화투통은 다음 판부터 바뀝니다  |

- 지갑이 모자라면 안내 문구가 **통장에서 끌어올 금액과 수수료**를 먼저 알려줍니다. 그것으로도 모자라면 얼마가 부족한지 적히고 개조를 맡길 수 없습니다.
- 예약이 걸려 있으면 뒷골목 메뉴의 **화투통 개조** 항목 옆에 「예약 중 · 예약금 ○○」이 함께 표시됩니다.

## 🎁 클리어 보상 모달

라운드 클리어 시 나타나는 **핵심 UI**. 게임 성장의 중심!

**진입:** 정산 화면 → 자동 전환 → 3가지 스킬 제시

**구성:** 상단 지갑 / 3개 스킬 카드 / 하단 버튼

**스킬 카드:**

- 등급은 8단계: **일반 → 중급 → 고급 → 최고급 → 영웅 → 불멸 → 유물 → 신화**. 등급마다 카드 색이 다르며, 최상위 두 등급은 유물(주홍빛), 신화(금빛)로 표시됩니다.
- POWER UP! 뱃지 (보유 스킬 강화 가능)
- 가격 배지 (초록=가능, 빨강=부족)
  **가격:** 스킬의 파워와 등급 프리미엄으로 정해지는 기본가(대략 `530 × 1.065^파워 × 등급 프리미엄`). 이미 보유한 스킬은 강화(레벨업) 가격으로 표시되며, 눈치 스탯과 단골 대우 스킬로 할인받을 수 있습니다. 등급별 가격표는 [SKILLS_PRICING.md](./SKILLS_PRICING.md) 참조.
  **인터랙션:**
- 데스크톱: 호버 툴팁 / 클릭 구매
- 모바일: 500ms 롱프레스 툴팁 / 탭 구매

**하단 버튼:**

- **물리기 (리롤)**: 스킬 3종 재추첨 — 무료 횟수가 남아 있으면 무료, 소진 후에는 **돈**으로 지불합니다 (다음 라운드 목표 점수의 약 3%에서 시작해, 리롤할 때마다 2%씩 복리 인상)
- **🎒 가방 (N/M)**: 인벤토리 열기
- **선택 안 함**: 스킬 없이 진행

**실시간 동기화:** 인벤토리 변경 시 잔액/슬롯/상태 즉시 반영

**영혼 시스템:** 귀신 품기 효과로 영혼 상태 → "소진됨" 비활성

### 기술 각성 (AwakenModal)

기술 2개 또는 3개 조합(레벨 무관, 보유만 하면 가능) → 신화/고유 등급:

- 조합 레시피 목록
- 성공 확률 (요행 스탯 영향)
- 비용 표시 (실패해도 차감)

## 🎁 보스 클리어 리워드 (RewardModal)

보스전 승리 후 **보상의 문**을 먼저 지납니다. 고른 문에 따라 뒤따르는 화면이 달라집니다.

```
정산 → 🚪 보상의 문 → (고른 문의 보상) → 기술 선택 화면
                       ├─ 🃏 기사 위탁 → 위탁 택1 → 패 추가/제거
                       ├─ 🤏 손기술    → 전리품 공개 연출
                       └─ ✨ 고귀한 봉투 → 봉투 선택 → 카드팩 오프닝
```

> **⚠️ 봉투는 이제 자동으로 열리지 않습니다.** 아래 봉투·카드팩 화면은 **고귀한 봉투** 문을 골랐을 때만 나타납니다.

### 1단계: 보상의 문 (Doors of Reward)

```
┌─────────────────────────────────────┐
│           [격퇴한 보스 초상]         │
│           🎊 두목 격퇴! 🎊           │
│            보상의 문                 │
│  "고른 문의 보상만 받습니다"         │
│      이번 판 고 5회 → 문 2개         │
│                                     │
│           남은 선택 2회              │
│  ┌───────────────────────────────┐  │
│  │ 🃏 기사 위탁          [선택함] │  │
│  ├───────────────────────────────┤  │
│  │ ✨ 고귀한 봉투                 │  │
│  ├───────────────────────────────┤  │
│  │ 🤏 손기술              [🔒잠김] │  │
│  └───────────────────────────────┘  │
│               [확인]                │
└─────────────────────────────────────┘
```

- **격퇴한 보스의 얼굴**: 방금 쓰러뜨린 보스의 초상과 이름이 문 위에 걸립니다. 축하의 자리이므로 봉투 선택과 같은 금테·색종이 연출을 씁니다(저사양 모드에서는 색종이가 생략됩니다).
- **문은 세로로 쌓입니다**: 위에서부터 기사 위탁 · 고귀한 봉투 · 손기술 순서로 서며, 이 순서는 판마다 바뀌지 않습니다.
- **원인 한 줄**: 문 위에 「이번 판 고 n회 → 문 m개」가 적혀, 문이 몇 개 열렸고 왜 그런지가 바로 읽힙니다.
- **남은 선택 알약**: 첫 문 바로 위에 「남은 선택 n회」가 서고, 고르거나 풀 때마다 즉시 갱신됩니다.
- **토글 선택**: 문을 누르면 **[선택함]** 배지가 붙고, 다시 누르면 풀립니다. 고른 문도 계속 눌립니다 — 잠기지 않습니다.
- **잠긴 문**: 고를 수 없는 문은 흐려진 채 **[🔒 잠김]** 배지와 함께 남고, 그 자리에 이유가 적힙니다(손기술을 이미 끝까지 익힘 / 지금 맡길 수 있는 위탁 없음).
- **[확인] 버튼**: 하나도 안 골랐거나 아직 더 고를 수 있으면 잠겨 있습니다. 자격을 다 써야 열립니다.
- **ESC로 닫히지 않습니다** — 반드시 하나 이상 고르고 나가는 화면입니다.
- **키보드·게임패드**: 열리는 즉시 첫 번째 고를 수 있는 문에 포커스가 잡힙니다. **Space**로 토글하고 **Enter**로 확정합니다.

### 2단계: 위탁 택1 (기사 위탁 문)

**기사 위탁** 문을 골랐을 때 이어지는 화면입니다.

- **기사가 앞장섭니다**: 위탁을 집행하는 인물이므로 페이즈와 관계없이 **기사**의 초상이 섭니다.
- **카드 격자**: 맡길 수 있는 위탁이 기술 상점과 **같은 얼굴의 카드**로 깔립니다(데스크톱 4열, 폰 2열). 가격 자리에는 **[받기]**가 섭니다 — 사는 것이 아니라 받는 자리이기 때문입니다.
- **열린 위탁 수**: 초상 아래 설명 끝에 「지금 열린 위탁 n/11」이 붙습니다. **수련의 여정**을 밟을수록 이 수가 늘어납니다. 아직 열리지 않은 위탁은 잠긴 카드가 아니라 **목록에 아예 없습니다.**
- **고를 수 없는 카드**: 이미 끝까지 키웠거나 지금 더미에 뺄 패가 없으면, 설명 자리에 그 이유가 대신 적히고 카드가 비활성됩니다.
- **취소 없음**: 문을 이미 소비했으므로 ESC·바깥 클릭으로 물러설 수 없습니다. 첫 번째 고를 수 있는 카드에 포커스가 잡힙니다.

### 3단계: 패 추가 / 카드 제거

위탁 기술은 받는 즉시 손봅니다 — 피 추가·피 제거·패 끼워넣기·패 빼돌리기는 **두 장**, 그 밖의 위탁은 **한 장**입니다. 그때 열리는 화면입니다.

- **후보 열**: 화면 위쪽에 고를 수 있는 패 후보가 늘어서고, 그 아래 「n장 중 m장」 안내가 붙습니다.
- **화투통 격자**: 그 아래에 **현재 화투통 전체**가 월 × 종류 격자로 펼쳐집니다. 각 칸이 장수이고, 가장자리에 종류 합계와 월 합계가 섭니다. 지금 낀 화투통이 밀어주는 종류에는 표시가 붙어, 내 덱의 구성과 구멍이 한눈에 읽힙니다.
- **추천 힌트**: 후보 카드에 **[추천] / [비추천]**(제거일 때는 **[빼기 추천] / [빼면 아까움]**) 배지와 순위가 붙습니다. 판단 기준(어느 전략을 기준으로 매겼는지)이 함께 표시되며, 후보끼리 우열이 없으면 그렇다고 알려줍니다.
- **증감 미리보기**: 카드를 짚거나 고르면 격자의 합계가 어떻게 달라지는지 미리 보여줍니다.
- **[취소] / [확인]**: 버튼은 **취소가 왼쪽, 확인이 오른쪽**입니다. 그 아래 한 줄로 「취소 시 기회만 소진됩니다」라는 경고가 붙습니다 — 물러설 수는 있지만 위탁 발동 기회는 돌아오지 않습니다.

### 4단계: 고귀한 봉투 선택 (Noble Envelopes)

```
┌─────────────────────────────────────┐
│      🎊 Boss Defeated! 🎊           │
│        Noble Envelopes              │
│  "...Choose one as your trophy..."  │
│                                     │
│  ┌──────┐  ┌──────┐  ┌──────┐       │
│  │Common│  │Rare  │  │Epic  │       │
│  │Card  │  │Card  │  │Card  │       │
│  │Image │  │Image │  │Image │       │
│  │      │  │      │  │      │       │
│  │ Desc │  │ Desc │  │ Desc │       │
│  └──────┘  └──────┘  └──────┘       │
│                                     │
│            [Skip Reward]            │
└─────────────────────────────────────┘
```

- **시각효과**: 선택 시 축하 폭죽(Confetti) 효과와 함께 봉투가 강조됩니다.
- **마법패 예고**: 봉투 표면에는 해당 봉투에서 나올 수 있는 대표 패의 이미지가 흐릿하게 비쳐 보입니다.
- **스킵**: 보상을 원치 않으면 하단 [건너뛰기] 버튼을 사용합니다 — 이 화면은 ESC로 닫히지 않습니다.

**봉투 등급별 비주얼:**

- **일반** (COMMON): 회색 테두리
- **고급** (RARE): 파랑 테두리 + 반짝임
- **희귀** (EPIC): 보라 테두리 + 빛남
- **전설** (LEGENDARY): 금색 테두리 + 광채

**봉투 커버 이미지:**

- 패키지 타입에 따라 대표 카드 스프라이트 표시
- 광 패키지 → 광 카드 이미지
- 동물 패키지 → 동물 카드 이미지
- 월별 패키지 → 해당 월 카드

### 5단계: 카드팩 오프닝 (PackOpeningAnimation)

봉투 선택 후 화려한 연출:

1. 선택한 봉투가 중앙으로 확대
2. 봉투가 열리며 카드들이 튀어나옴
3. **카드 하나씩 뒤집기**:
   - 뒷면 → 앞면 회전 애니메이션
   - 등급별 파티클 효과
   - 효과음 (찢는 소리, 반짝임)
4. 모든 카드 공개 후 **덱 편입 확인**
5. 연출 진행/스킵은 화면의 버튼으로 조작합니다

### 결정 화면의 공통 규칙

보상·개조처럼 **무언가를 고르는 화면**은 같은 관례를 따릅니다.

- **버튼 순서**: 물러설 수 있는 화면에서는 **[취소]가 왼쪽, [확인]이 오른쪽**입니다. 되돌릴 수 없는 선택에는 버튼 아래 한 줄로 경고가 붙습니다.
- **기본 포커스**: 화면이 열리면 **첫 번째로 고를 수 있는 항목**에 포커스가 잡혀, 게임패드·키보드로 바로 움직일 수 있습니다. 잠긴 항목은 건너뜁니다.
- **키 조작**: **Space**로 포커스한 항목을 고르거나 풀고, **Enter**로 확정합니다.
- **ESC**: 보스전 보상 화면 — **보상의 문 · 위탁 택1 · 고귀한 봉투** — 은 ESC로 닫히지 않습니다. 물러설 길이 있다면 화면 안의 버튼([확인] · [건너뛰기])이 그 길입니다. 반대로 패 추가·카드 제거나 화투통 개조처럼 화면 안에 [취소]가 있는 곳은 ESC로도 같은 취소가 걸립니다.
- **잘못 눌러도 됩니다**: 문과 카드 선택은 **토글**이라 다시 눌러 풀 수 있습니다. 확정은 [확인]을 눌렀을 때만 일어납니다.

### 글로우 타입

- **⭐ 고점수**: 황금빛 (광, 단, 고도리, 5장 연월)
- **🌈 조합패 2개(멀티플)**: 무지개 블러 (흐르는 그라디언트)
- **🌟 조합패 3개+(메가 멀티플)**: 강렬한 무지개 (빠른 애니메이션)

## 🏆 풀스크린 점수 배너

한 번에 매우 큰 점수를 내면 화면 전체를 덮는 배너가 터집니다:

- **FLAWLESS VICTORY**: 10억 점 이상
- **FATALITY**: 100억 점 이상

배너는 **한 판(런) 안에서 도달한 최고 기록을 처음 넘어설 때만** 나옵니다 — 후반에 매 턴 같은 연출이 반복되어 루즈해지지 않도록 의도된 동작입니다. 암전·파티클 등 나머지 타격 연출은 매번 유지됩니다.

또한 점수·금액이 아주 커지면 점수판, 수수료 표기 등 UI 곳곳에서 자동으로 **축약 표기**(만/억/조 단위)로 전환되어 자릿수가 화면을 넘치지 않습니다.

## 🎮 게임 메뉴 시스템

**ESC 키** 또는 상단 **라운드 버튼** 클릭으로 게임 내 메뉴에 진입합니다.

### 진입 조건

- 게임 플레이 중 (`PLAYING` 상태)
- 처리 중이 아닐 때 (`isProcessing = false`)
- 다른 모달이 열려있지 않을 때
- 마스터숍이 열려있으면 마스터숍을 먼저 닫음

### 메뉴 항목

- **계속하기**: 메뉴를 닫고 게임으로 복귀
- **다시하기**: 현재 게임을 종료하고 새 게임 시작
- **타짜비급**: 갤러리 화면 (수집 요소 열람)
- **환경설정**: 다음 세부 항목들을 조정할 수 있는 설정 화면으로 진입합니다.
  - **사운드**: 마스터 볼륨, 배경음(BGM) 볼륨 및 켜기/끄기 설정.
  - **언어 및 해상도**: 표시 언어(한국어, 영어, 일본어 등) 및 윈도우 해상도 선택.
  - **게임 힌트**: 5초 무조작 시 자동 힌트 흔들림 토글.
  - **카드 번호 표시**: 활성화 시 모든 카드 우측 상단에 해당 카드의 고유 번호(월 숫자 배지)가 항상 표시되어 족보 분석 및 카드 구별이 편리합니다.
  - **레트로 효과 및 픽셀 크기**: CRT 스타일 픽셀 필터 및 강도 조정.
  - **저사양 성능 모드 (lowPerf)**: 활성화 시 2.5D 캐릭터 초상화가 Canvas 2D 평면 스프라이트로 동적 폴백하여, WebGL 연산 및 VRAM(비디오 메모리) 부하를 대폭 줄여줍니다.
  - **데이터 관리**: 튜토리얼 초기화, 플레이 기록 초기화, 세이브 데이터 완전 초기화 기능 제공.
- **타이틀로**: 진행 상황을 저장하고 타이틀 화면으로 돌아가기

## ⌨️ 키보드 단축키

### 게임 중

|       키        | 기능           | 설명                                        |
| :-------------: | :------------- | :------------------------------------------ |
|      **H**      | 족보 이력      | 사용/버린 카드 (모달)                       |
|      **R**      | 족보표         | 족보 종류/배수 확인                         |
|      **I**      | 인벤토리       | 보유 기술 목록                              |
|      **D**      | 덱 뷰어        | 남은 카드 확인                              |
|      **M**      | 뒷골목         | 상점 이동 (보스전 중 불가)                  |
|      **T**      | 스탯 관리      | 캐릭터 스탯 투자/관리                       |
|     **F7**      | 스톱           | 라운드 종료 (스톱 버튼 표시 중)             |
| **U** / **Ctrl+Z** | 무르기      | 직전 액션 되돌리기                          |
|     **F8**      | 힌트           | 낼 수 있는 조합 카드 흔들기                 |
|     **F10**     | 게임 메뉴      | 모달이 있으면 닫기, 없으면 게임 메뉴        |
|     **1~8**     | 카드 선택      | N번째 카드 토글                             |
|     **Del**     | 묻기           | 선택 카드 버림                              |
|     **Alt**     | 월 표시 (홀드) | 누르는 동안 모든 카드에 월 번호 표시        |
|     **F9**      | 월 표시 (토글) | 화면상의 모든 카드에 월 번호 표시 토글      |
|     **ESC**     | 닫기/게임 메뉴 | 열린 UI를 하나씩 닫고, 없으면 게임 메뉴     |

### 단축키 우선순위

1. ESC: 전체 화면 표면(컷신·설정 등) → **모달·인벤토리**(나중에 연 것부터) → 뒷골목(상점) → 게임 메뉴
2. H/R/I/D/M/T: 모달 없을 때만 작동
3. 음소거 토글(Ctrl+Shift+M)은 데스크톱 앱 전용 메뉴 단축키입니다

### 키보드 포커스 표시

- 키보드/게임패드로 조작하면 현재 위치가 **금색 테두리(#ffd700) 포커스 링**으로 표시됩니다. 마우스를 쓰면 자동으로 사라집니다.
- 게임패드 사용 시(Steam Deck 포함) 화면 버튼 위에 대응하는 패드 버튼 배지가 표시되며, Alt/F9 키로도 배지를 켤 수 있습니다.

> 이 표는 요약본입니다. 모든 키와 게임패드 매핑을 담은 치트시트는 공식 문서의 키보드 단축키 페이지([KEYBOARD_SHORTCUTS.md](./KEYBOARD_SHORTCUTS.md))에 있습니다.

## 💬 NPC 말풍선 시스템

게임 내 캐릭터 대사를 전달하는 **NpcSpeechBubble** 시스템입니다.

### 표시 방식

- **보스전**: `BOSS_SPEECH` 이벤트 → 보스 오버레이 내 대사 표시
- **평상시**: `NPC_SPEECH` 이벤트 → 화면 하단 말풍선 UI

### 대사 출력 캐릭터

| 캐릭터          | 상황                                             |
| :-------------- | :----------------------------------------------- |
| **뽀찌꾼**      | 입막음 성공/밀고(기술 압수)/감시                 |
| **해결사**      | 자산 몰수 시                                     |
| **점주**        | 상점 인사/배웅 — 페이즈에 따라 화자가 바뀝니다   |
| **노인 (스승)** | 기술 전수 시                                     |
| **상무**        | 빚 상환·은행 업무 시                             |

### 비주얼 연출 및 동작

- **2.5D 및 스프라이트 초상화 탑재**: 기존 텍스트 대화창이나 UI 곳곳에 혼용되던 캐릭터 에모지(Emoji) 식별자들을 2.5D 포트레이트 및 이에 대응하는 2.5D 정적 스프라이트 폴백(Fallback)으로 대체하여 하드보일드 느와르 비주얼을 완성했습니다.
- **말풍선 흔들림 제거**: 텍스트 가독성을 최적화하고 시각적 산만함을 방지하기 위해 말풍선이 둥둥 떠다니던 흔들림(Bobbing/Floating) 애니메이션이 제거되었습니다.
- `CheatManager.emitCharacterSpeech()`: 보스전 여부에 따라 자동 분기되어 대사를 출력합니다.
- 말풍선에 캐릭터 초상(2.5D/Fallback), 이름, 대사가 정적으로 표시되며 일정 시간 후 자동 소멸합니다.
